# ReactPro

PWA para gravar reações a vídeos: câmera frontal em cima, vídeo embaixo.
A gravação é montada num canvas (fundo + câmera + vídeo) e salva no próprio celular;
botões e menus não aparecem no vídeo final. Nada é enviado para servidor.

- Abrir: https://neaguson.github.io/reactpro/
- Testar localmente: `python -m http.server 8790` nesta pasta e abrir http://localhost:8790
- Ícones (a partir de `assets/logo-mk.svg`, usa o Edge): `pwsh tools/make_icons.ps1`
